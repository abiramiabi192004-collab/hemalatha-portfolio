## 🚀 How to Run Locally

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/hemalatha-portfolio.git
   cd hemalatha-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000/` in your browser.

4. **Build production bundle**:
   ```bash
   npm run build
   ```
   Outputs production-ready static bundle in `dist/`.
